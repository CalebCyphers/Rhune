# Dice assets

Simple, stylized dice icons used by the bot.

- `d6-1.png`..`d6-6.png`
- `d20-1.png`..`d20-20.png`
- `d4-1.png`..`d4-4.png`
- `d8-1.png`..`d8-8.png`
- `d10-1.png`..`d10-10.png`
- `d12-1.png`..`d12-12.png`

The d4/d8/d10/d12 faces are generated by `scripts/gen-dice-assets.js`
(run it from the repo root to regenerate; idempotent). The d6/d20 art predates
that script.

These are attached to Discord messages and referenced from embeds using
`attachment://...` URLs — a single die as a thumbnail, multiple dice of one
type as a rendered strip (`lib/pool_strip.js`).
